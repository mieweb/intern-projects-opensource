# Open-Access Journal and Conference Target List for AI / Medical Informatics / Robotics Interns

Updated: 2026-06-06

Purpose: help interns select high-quality open-access papers to present, and identify realistic publication or poster targets for stronger rotation projects.

Notes:
- `Rank` is an approximate prestige / citation-weight ranking, not a strict impact-factor ranking.
- `OA status` distinguishes fully open-access journals from hybrid journals where authors may choose open access.
- Journal submissions are generally rolling unless otherwise noted.
- Conference dates shift yearly; approximate dates should be re-checked before assigning submission work.

## Suggested intern assignment format

| Deliverable | Requirement |
|---|---|
| Paper selection | Pick one peer-reviewed open-access paper from the top 5–7 venues in the relevant area. |
| Presentation | 20 minutes: 5 min background, 5 min methods, 5 min results, 3 min critique, 2 min build/research idea. |
| Reproducibility | Find the code/data if available; identify what would be needed to reproduce the core result. |
| Repository artifact | Add a Markdown summary, citation, PDF link, notes, and a “what we could build” section. |
| Stretch goal | Produce a 2–4 page reproducible note, JOSS/TMLR-style artifact, workshop abstract, or poster draft. |
